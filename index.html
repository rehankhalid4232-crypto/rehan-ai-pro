Connect chart data feed

This prototype can read candles from your own HTTPS REST endpoint or WebSocket feed. It does not log in to Quotex, scrape its private interface, or place trades. Use only a data source you are authorized to access.

Feed JSON format and technical notes

REST response: {"candles":[{"open":1.08,"high":1.081,"low":1.079,"close":1.0805}, ...]}. WebSocket can send the same JSON object repeatedly. Send at least 20 closed OHLC candles in chronological order. For OTC, feed must match the exact OTC asset and quotes shown on your Quotex screen; generic FX feeds are not a substitute.
